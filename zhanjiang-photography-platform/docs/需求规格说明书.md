## 1. 项目概述

### 1.1 项目背景

随着社交媒体和自媒体的发展，高校大学生对于个人形象照片的需求日益增长。无论是毕业照、个人写真、活动跟拍还是日常记录，专业摄影服务需求旺盛。湛江地区高校众多，学生群体庞大，但缺乏一个专门针对大学生的约拍平台，导致供需双方信息不对称。

### 1.2 项目目标

构建一个基于微信小程序的约拍平台，连接湛江地区高校的摄影爱好者/专业摄影师与有拍摄需求的大学生，实现：

- 为客户提供便捷的摄影师发现、预约、沟通、交付服务
- 为摄影师提供展示作品、获取订单、管理业务的工具
- 为平台提供完善的用户管理、内容审核、数据统计功能
- 打造湛江高校约拍品牌，建设摄影灵感社区

### 1.3 用户角色定义

| 角色 | 描述 |
|-----|------|
| 客户（寻求约拍者） | 有拍摄需求的大学生，发布需求、预约摄影师、接收作品 |
| 摄影师（服务提供者） | 提供摄影服务的学生或专业人士，展示作品、接受预约、交付成片 |
| 平台管理员 | 管理平台运营，包括用户审核、内容审核、数据统计等 |

## 2. 功能需求

### 2.1 客户端功能模块

#### 2.1.1 需求发布 (FR-C-001)

**功能描述**：客户可快速发布拍摄需求，让摄影师主动联系或竞标。

| 功能点 | 详细描述 |
|-------|---------|
| 需求类型选择 | 支持人像、毕业照、活动跟拍、情侣照、闺蜜照、证件照等多种类型 |
| 基本信息填写 | 拍摄时间（日期+时段）、地点（定位/手动输入）、拍摄时长 |
| 风格选择 | 日系、韩系、复古、小清新、ins风、中国风、黑白等 |
| 预算设置 | 设置预算范围（如100-300元） |
| 详细描述 | 文字描述具体需求，支持上传参考图片（最多9张） |
| 需求状态 | 征集中、已确定摄影师、已完成、已取消 |

**业务规则**：
- 需求发布后24小时内可免费修改
- 需求有效期默认7天，可续期
- 同一时间最多发布3个活跃需求

#### 2.1.2 摄影师发现 (FR-C-002)

**功能描述**：浏览、搜索、筛选摄影师，查看作品集和详情。

| 功能点 | 详细描述 |
|-------|---------|
| 推荐列表 | 根据用户偏好、位置、评分等智能推荐摄影师 |
| 搜索功能 | 支持摄影师昵称、风格标签、学校等关键词搜索 |
| 筛选条件 | 风格、评分范围、价格范围、距离、档期可用性、性别 |
| 排序方式 | 综合推荐、评分最高、价格从低到高、距离最近、订单数最多 |
| 摄影师卡片 | 展示头像、昵称、评分、代表作、起步价、接单数、标签 |
| 个人主页 | 详细介绍、作品集、服务项目、评价列表、档期日历 |

#### 2.1.3 在线沟通 (FR-C-003)

**功能描述**：与摄影师进行实时沟通，讨论拍摄细节。

| 功能点 | 详细描述 |
|-------|---------|
| 即时消息 | 支持文字、图片、语音消息 |
| 快捷回复 | 预设常用语句快速发送 |
| 位置发送 | 发送拍摄地点定位 |
| 订单卡片 | 在聊天中发送/查看订单信息卡片 |
| 消息通知 | 新消息微信服务通知提醒 |
| 聊天记录 | 历史消息云端存储，可随时查看 |

#### 2.1.4 预约下单 (FR-C-004)

**功能描述**：选择服务项目并完成预约支付。

| 功能点 | 详细描述 |
|-------|---------|
| 服务选择 | 浏览摄影师服务套餐，选择具体项目 |
| 时间选择 | 查看摄影师可用档期，选择拍摄日期和时段 |
| 地点确认 | 确认或修改拍摄地点 |
| 订单备注 | 填写特殊要求或备注信息 |
| 费用明细 | 展示服务费、优惠、实付金额 |
| 支付方式 | 微信支付 |
| 订单确认 | 支付成功后生成订单，发送通知 |

**支付规则**：
- 下单时支付全款或定金（由摄影师设置）
- 定金比例：30%-50%
- 尾款在拍摄完成后、作品交付前支付

#### 2.1.5 订单管理 (FR-C-005)

**功能描述**：查看和管理所有订单。

| 订单状态 | 描述 | 可执行操作 |
|---------|------|-----------|
| 待接单 | 已支付，等待摄影师确认 | 取消订单（全额退款） |
| 待拍摄 | 摄影师已接单，等待拍摄 | 改期、取消订单（扣手续费） |
| 拍摄中 | 拍摄进行中 | 联系摄影师 |
| 待选片 | 拍摄完成，等待选片 | 查看原片、选片 |
| 待交付 | 选片完成，等待精修交付 | 催促交付 |
| 待确认 | 作品已交付，等待确认 | 确认收货、申请售后 |
| 已完成 | 订单完成 | 评价、再次预约 |
| 已取消 | 订单已取消 | 查看退款详情 |
| 售后中 | 申请售后处理中 | 查看进度 |

#### 2.1.6 作品交付 (FR-C-006)

**功能描述**：在线接收并确认作品。

| 功能点 | 详细描述 |
|-------|---------|
| 原片预览 | 查看拍摄原片（带水印） |
| 选片功能 | 根据套餐选择指定数量精修片 |
| 精修交付 | 接收高清精修作品（无水印） |
| 作品下载 | 下载作品到本地相册 |
| 云端存储 | 作品云端保存30天 |
| 确认收货 | 确认作品无误，完成订单 |

#### 2.1.7 评价与分享 (FR-C-007)

**功能描述**：对摄影师进行评价，分享作品。

| 功能点 | 详细描述 |
|-------|---------|

| 图片评价 | 上传拍摄成片作为评价配图（最多9张） |

| 动态分享 | 将作品分享到平台灵感社区 |
| 朋友圈分享 | 生成精美海报分享到微信朋友圈（模拟） |

#### 2.1.8 收藏与关注 (FR-C-008)

**功能描述**：收藏喜欢的内容，关注摄影师。

| 功能点 | 详细描述 |
|-------|---------|
| 收藏摄影师 | 收藏喜欢的摄影师，方便下次查找 |
| 收藏作品 | 收藏喜欢的样片/作品 |

**功能描述**：浏览精选作品和攻略，获取拍摄灵感。

| 功能点 | 详细描述 |

## 3. 非功能需求

### 3.1 性能需求

| 指标 | 要求 |
|-----|------|
| 页面加载时间 | 首屏加载 < 2秒 |
| 接口响应时间 | 普通接口 < 500ms，复杂查询 < 2s |
| 并发用户数 | 支持1000+并发用户 |
| 图片加载 | 支持渐进式加载、缩略图预览 |

### 3.2 安全需求

| 安全措施 | 描述 |
|---------|------|
| 数据加密 | 敏感数据AES加密存储，传输HTTPS |
| 身份认证 | JWT Token认证机制 |
| 权限控制 | 基于角色的访问控制（RBAC） |
| 防攻击 | SQL注入、XSS、CSRF防护 |
| 实名认证 | 用户实名+学生身份验证 |
| 隐私保护 | 联系方式加密展示，定位模糊化 |

### 3.3 可用性需求

## 5. 接口设计概要

### 5.1 接口规范

- 协议：HTTPS
- 格式：RESTful API
- 数据格式：JSON
- 认证方式：JWT Bearer Token
- 版本控制：URL版本 /api/v1/

### 5.2 响应格式

```json
{
  "code": 200,
  "message": "success",
  "data": { },
  "timestamp": 1706972400000
}
```

### 5.3 核心接口列表

| 模块 | 接口 | 方法 | 描述 |
|-----|------|-----|------|
| 用户 | /api/v1/user/login | POST | 微信登录 |
| 用户 | /api/v1/user/profile | GET/PUT | 获取/更新用户信息 |
| 摄影师 | /api/v1/photographer/list | GET | 摄影师列表 |
| 摄影师 | /api/v1/photographer/{id} | GET | 摄影师详情 |
| 作品 | /api/v1/works/upload | POST | 上传作品 |
| 需求 | /api/v1/demand/publish | POST | 发布需求 |
| 订单 | /api/v1/order/create | POST | 创建订单 |
| 订单 | /api/v1/order/{id}/status | PUT | 更新订单状态 |
| 支付 | /api/v1/pay/create | POST | 发起支付 |
| 消息 | /api/v1/message/send | POST | 发送消息 |
| 社区 | /api/v1/community/post | POST | 发布动态 |
